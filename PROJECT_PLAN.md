# Project Execution Plan

## Research question

How does increasing class imbalance affect the performance of different machine-learning models for binary network intrusion detection?

## Phases

1. Inspect repository and establish a clean baseline.
2. Research candidate public datasets and document a defensible selection.
3. Add reproducible data acquisition and exploratory-analysis instructions.
4. Implement leakage-aware preprocessing, models, metrics, and controlled imbalance sampling.
5. Add automated tests and execute experiments on the selected dataset when available.
6. Generate machine-readable metrics and purposeful figures from executed runs.
7. Write the research report, limitations, and reproducibility documentation from verified evidence.
8. Run a final code, data, documentation, and security audit before committing.

## Integrity rules

- No numerical result will be written unless produced by an executed experiment.
- Dataset claims and citations will be verified against authoritative sources.
- Raw datasets and credentials will not be committed.
- If the selected data cannot be downloaded or reproduced in this environment, that limitation will be recorded rather than replaced with simulated results.
